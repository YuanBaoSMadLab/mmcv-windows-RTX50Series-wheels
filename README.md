# MMCV 2.1.0 Windows Wheels for RTX 50 Series (Blackwell)

Prebuilt MMCV 2.1.0 wheels for NVIDIA RTX 50 Series (Blackwell) on Windows.
Python 3.10, PyTorch 2.12, CUDA 13.2.
Official Windows wheels are not provided by OpenMMLab for this configuration.

Download:
https://github.com/YuanBaoSMadLab/mmcv-windows-RTX50Series-wheels/releases/tag/V1.0.0

本仓库提供 MMCV 2.1.0 的 Windows 预编译 Wheel，专为 RTX 50 系列（Blackwell）显卡编译，

安装方式（PowerShell）:
